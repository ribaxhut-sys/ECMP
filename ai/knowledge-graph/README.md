## Purpose
Represent relationships across Business → Capability → Domain → FRD → API → Event → Test for impact analysis and AI retrieval.

## Files
- `graph.generated.yaml` — **canonical** machine-readable graph, generated by `tools/generate_knowledge_graph.py` from ontology + traceability + OpenAPI + FRD + ADR. Do not edit by hand.
- `graph.generated.md` — **canonical** human-readable mermaid view (generated alongside the YAML).
- `graph.yaml` / `graph.md` — DEPRECATED manual snapshots kept for history only; they are not inputs to the generator.

## How AI should use it
When asked "what is impacted by changing X?", traverse neighbors in `graph.generated.yaml` (or use `python tools/eos.py impact --id <ID>`).
