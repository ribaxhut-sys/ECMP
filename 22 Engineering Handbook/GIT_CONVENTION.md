## Branch Naming
- `feature/<id>-short-name`
- `fix/<id>-short-name`
- `chore/<short-name>`
- `docs/<short-name>`

## Commit Message
```text
<type>(<scope>): <summary>

<body optional>
```

Types: `feat`, `fix`, `docs`, `refactor`, `test`, `chore`, `perf`

Example: `feat(ecmf): add case assignment transition guard`
